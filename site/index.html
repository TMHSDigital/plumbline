The ECE floor

A perfectly calibrated model does not score an Expected Calibration Error of zero on a finite sample. It scores something above zero, and how far above depends on how many rows you have. Enter a configuration to see that floor, and optionally a measured ECE to see whether it clears it.

What computes this

This calculator is a JavaScript reimplementation of plumbline's synthetic_floor(n, n_bins, accuracy), not the Python itself. It reproduces numpy's seeded random stream draw for draw (the PCG64 generator and numpy's own normal, gamma, and beta samplers), so with the same seeds it redraws exactly the outcomes the Python draws. It is checked against values exported from the Python on every change, in CI, and the site does not deploy if they disagree by more than 1e-9. The checked values are in floor-golden.json; the check is scripts/check_floor_parity.mjs.

The floor here is built from summary numbers: it invents n predicted probabilities averaging your accuracy. A plumbline report uses calibration_floor on your actual predictions instead, which conditions on how they are spread, so its floor for the same row count can differ. Use this page to plan and to sanity-check; use the report for the verdict on a real run.
