# Public datasets

Placeholder. The JevBench public loader lands here in Phase 7.

Whatever ends up in this directory is a smoke-test fixture, something real to run
on day one, and nothing more. plumbline is not reproducing anyone's benchmark.

Your own data goes in `datasets/private/`, which is gitignored. That is the
intended path for real use, and it is the only path on which plumbline's
recalibration numbers mean anything.
